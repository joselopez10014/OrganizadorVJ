# Milestones
# M0 Modelo del problema
Analizar el problema de la HU1 para entender que elementos y relaciones son necesarias para representar el problema. Se entregara un codigo que represente el problema y sera válido cuando represente todos los elementos y relaciones del problema de la HU1.
# M1 Obtención de la información
Diseñar un código inicial que permita la identificación y recopilación de información relevante para el problema desde una página web. Se considerara viable cuando el código sea capaz de identificar y recopilar de forma consistente los datos necesarios para resolver el problema de la HU1.
